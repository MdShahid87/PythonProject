# 🧮 Simple Python Calculator

A beginner-friendly calculator built with Python that performs basic arithmetic operations using functions, loops, conditional statements, and exception handling.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (\*)
- Division (/)
- Division-by-zero protection
- Input validation using `try-except`
- Repeat calculations until the user exits

## 🛠️ Technologies Used

- Python 3
- Functions
- `while` loop
- `if-elif-else`
- Exception handling

## 🚀 Installation and Setup

**1. Install Python 3**

Download Python from [python.org](https://www.python.org/downloads/).

**2. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

**3. Open the project folder**

```bash
cd simple-calculator
```

**4. Run the calculator**

```bash
python calculator.py
```

On some systems, use `python3 calculator.py` instead.
